# MoneyMate — 내 PC에서 처리하는 카드·은행 내역 분석

카드·은행 내역 CSV를 올리면 **내 PC에서** 자동으로 분류하고, **중복 결제 · 유난히 큰 지출 · 처음 보는 가맹점의 고액 · 정기결제 금액 변동**을 근거 숫자와 함께 알려주며 **예산 초과를 미리 경고**합니다. (인공지능 응용 시스템 개발 종합 프로젝트, 작성자 반재영)

- **내역이 밖으로 나가지 않음**: 원본 CSV는 저장하지 않고, AI(선택)에는 분류되지 않은 가맹점의 **이름만** 보냅니다(금액 제외).
- **금액은 코드가 계산**: 모든 금액은 정수 원, 합계·증감·경고 문장의 숫자는 AI가 아니라 코드가 만듭니다. 읽지 못한 줄은 줄 번호와 이유를 알려줍니다.
- **분류**: 가맹점 이름 정리 → 내가 고친 규칙 → 키워드 사전. 처음 보는 가게는 직접 고치면(같은 가맹점 전체에 적용·기억) 되고, AI 제안은 "AI 제안(미확인)"으로 표시됩니다.
- **설명 가능한 이상 탐지**: 중앙값·MAD 기반, 경고마다 근거 숫자(평소 금액의 몇 배인지 등)와 "정상이에요(숨기기)".
- **항상 동작**: AI가 없어도 가져오기·분류·분석·예산이 모두 동작합니다.

## 실행

필수: Node.js 24 이상 (npm 설치 없음)

```powershell
node server.mjs        # 또는 시작하기.cmd 더블클릭
```
브라우저에서 http://127.0.0.1:5600 (내 PC에서만 열림). 처음이라면 "샘플로 체험하기"를 눌러 보세요(가상 데이터).

### AI 분류 제안(선택)
Ollama를 설치하고 `ollama pull kanana2:3b`. `.env.example`을 `.env`로 복사해 `LLM_PROVIDER=ollama` 등을 설정합니다. Claude·ChatGPT 키도 쓸 수 있습니다(가맹점 이름이 외부로 나가므로 주의).

## 지원하는 CSV
카드(날짜·가맹점·이용금액·구분) 또는 은행(거래일시·적요·출금액·입금액·잔액) 형식. UTF-8·CP949, 쉼표·탭 구분, 헤더 앞의 안내 문구와 끝의 합계 줄은 건너뜁니다. 5MB·50,000행까지. 헤더 이름이 낯설면 거래표를 못 찾았다고 안내합니다(`src/ledger.mjs`의 별칭 표에 추가하면 됩니다).

## 테스트·평가

```powershell
npm test                          # 자동 테스트 36개
python tools/mutate.py            # 변이 검사(핵심 로직 12곳을 망가뜨려 테스트가 잡는지 확인)
node tools/eval.mjs               # 읽기·분류·이상 지출 정확도(개발용·held-out 세트)
node tools/eval.mjs held2 --llm   # + AI 분류 제안 정확도(Ollama 필요)
```

평가 결과와 한계는 `docs/MoneyMate_테스트결과서.md`에 있습니다. **평가에 쓴 거래내역은 모두 직접 만든 가상 데이터입니다. 실제 카드 내역의 복잡함은 반영되지 않았으므로 정확도는 상한선으로 해석하세요.**

## 구성

| 파일 | 역할 |
|---|---|
| `src/csv.mjs` | 글자 해석(UTF-8/CP949)·CSV 파싱 |
| `src/ledger.mjs` | 행 → 거래(날짜·정수 금액·종류), 읽지 못한 줄 보고 |
| `src/merchant.mjs` | 가맹점 이름 정리·키워드 분류 |
| `src/analyze.mjs` | 월 요약·이상 지출·정기결제·예산 |
| `src/ai.mjs` | AI 분류 제안과 검증 |
| `src/db.mjs` | SQLite 6개 테이블(CHECK·UNIQUE·CASCADE) |
| `src/app.mjs`·`http.mjs` | 서비스 흐름, HTTP API·보안 |
| `tools/gen.mjs` | 평가용 가상 거래내역 생성기(시드 고정, 정답 포함) |
| `docs/` | 기획서·요구사항 분석서·명세서·데이터정의서·개발일정표·테스트결과서·포트폴리오·발표자료 |

## 한계
- 평가는 가상 데이터로만 했습니다(실제 평가는 12월 예정).
- 처음 보는 가맹점은 분류되지 않습니다(최종 평가 세트에서 규칙 분류율 58%, 분류한 것의 정밀도는 100%). 직접 고치거나 AI 제안을 확인하세요.
- AI 제안의 정밀도는 56%(3B 모델)입니다. 확인 전에는 "미확인"입니다.
- 이상 탐지의 15만원·20만원 기준은 절대 금액이라 소비 규모가 큰 사용자에게는 오탐이 있을 수 있습니다.
- 로그인이 없어 127.0.0.1에서만 열립니다(외부 공개 금지).
