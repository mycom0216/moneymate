## 3. 인터페이스 명세(API)

| 메서드·경로 | 설명 | 주요 입력 | 응답 |
|---|---|---|---|
| GET /api/status | AI 상태, 카테고리 목록, 한도 | – | llm, categories, limits |
| POST /api/llm/reconnect | AI 다시 연결 | – | llm |
| GET /api/sample | 시연용 샘플 CSV(가상 데이터) | – | filename, csv |
| POST /api/import?userId&filename | CSV(바이너리 본문) 가져오기 | 본문=파일 바이트 | added, duplicates, skippedCount, skipped[], months, unclassified / 415·413·400·429 |
| GET /api/report?userId&month | 월 리포트 | month=YYYY-MM(생략 시 최신) | summary, alerts, dismissedCount, recurring, budgets, imports |
| GET /api/transactions?userId&month&category&q&offset | 거래 목록 | – | total, rows[] |
| POST /api/transactions/category | 분류 고치기 | userId, txId, category, remember | updated |
| POST /api/classify/ai | 미분류 가맹점 AI 제안 | userId | asked, suggested, updatedTransactions / 503 |
| POST /api/budgets | 예산 설정·삭제 | userId, category, limit(null=삭제) | ok |
| POST /api/alerts/dismiss · /restore | 경고 숨기기·되돌리기 | userId, key | ok · restored |
| POST /api/imports/delete | 가져온 파일 삭제 | userId, importId | ok / 404 |
| GET /api/export?userId&month | 월 리포트 .md | – | 마크다운 첨부 |
| POST /api/forget | 내 기록 전체 삭제 | userId, confirm:true | deleted |
| GET /api/stats | 운영 지표 | – | users, imports, transactions, byMethod |

오류 코드: 400 입력 오류 · 404 대상 없음(남의 것 포함) · 413 크기 초과 · 415 텍스트가 아닌 파일 · 429 요청 간격 · 503 AI 사용 불가 · 500 일반 문구.

## 4. 데이터 요구사항

테이블 6개(users, imports, transactions, merchant_rules, budgets, dismissals), 금액 양수·종류·카테고리·날짜·"수입 ⇔ 수입 카테고리"를 DB CHECK로 강제, `UNIQUE(user_id, dedupe_key)`로 중복 방지, 사용자 삭제 시 전부 연쇄 삭제 → 「데이터정의서」 참조.
